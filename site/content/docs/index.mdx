**Macaron Artifacts** is one local WebUI for Claude Code, Codex, OpenCode, pi, Hermes, and OpenClaw. Install one package, start one server, and choose the harness per conversation.

## What You Get

<Cards>
  <Card title="Shared Interface" href="/docs/usage">Choose a harness, workspace, Profile, and model in the same conversation interface.</Card>
  <Card title="Live Chat" href="/docs/usage">Stream native text, reasoning, tool input, approvals, and command output as each harness exposes them.</Card>
  <Card title="Generated UI" href="/docs/usage">Render inline `ui4a/tsx` blocks and persistent `.artifacts` Canvas files with the same React runtime.</Card>
  <Card title="Shared Themes" href="/docs/usage">Shiki theme families drive syntax highlighting, interface tokens, and generated components.</Card>
</Cards>

Head to [Usage](/docs/usage) to install and run the WebUI, or read [Architecture](/docs/architecture/overview) for the current implementation.
