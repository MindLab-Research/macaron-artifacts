**Macaron Artifacts** brings Generative UI to the coding agent you already use. It is one local WebUI where [Claude Code](https://github.com/anthropics/claude-code), [Codex](https://github.com/openai/codex), [OpenCode](https://github.com/anomalyco/opencode), [pi](https://github.com/earendil-works/pi), [Hermes](https://github.com/NousResearch/hermes-agent), and [OpenClaw](https://github.com/openclaw/openclaw) answer with working interfaces — rendered while the reply is still streaming. Install one package, start one server, and choose the harness per conversation.

It is the community edition of **UI4A** (UI for Agent) from [Mind Lab](https://www.mindlab.im). Raw HTML gives the model freedom with no contract; schema protocols such as [A2UI](https://a2ui.org) give control but cap what it can express. UI4A lets the agent write ordinary React — imports, components, state — and has the runtime decide what that code can reach. The design and benchmarks are in [UI4A: A Component-Native Harness for Generative UI](https://www.mindlab.im/updates/ui4a-a-component-native-harness-for-generative-ui).

## Why UI4A

- **Streaming render** — a component paints while its source is still arriving, so the first useful pixels land long before the reply ends.
- **State that survives** — the interface is interactive from the first frame; later chunks don't reset what you've clicked, typed, or dragged.
- **Components and npm** — use the bundled `$ui4a/ui` library, KaTeX, charts, and Headless UI, or import other npm packages through the CDN. Everything follows the app's theme tokens.
- **Wired to the host** — generated components get scoped chat, state, and file capabilities, so a button can start the next turn or a form can save to `.artifacts`.
