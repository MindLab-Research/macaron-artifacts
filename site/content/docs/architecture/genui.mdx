title: GenUI

UI4A lets a harness produce a real React interface alongside its answer. The same runtime handles both inline conversation blocks and files in the session workspace, independent of which harness generated them.

## Two delivery forms

- **Inline:** a complete module in a fenced `ui4a/tsx` block renders inside the assistant message as its source arrives.
- **Canvas:** `.artifacts/canvases/<id>.ui4a.tsx` opens in the side panel. Supporting `.tsx`, `.ts`, `.jsx`, `.js`, and `.json` modules resolve through explicit relative imports.

`artifacts/src/web/ui4a/Ui4aSurface.tsx` feeds source to `partial-react@0.0.6`. The renderer uses `pushCode`/`finish`, preserves the last good frame while syntax is incomplete, and keeps a shared React instance so state survives incremental updates.

## Host modules

The manifest in `artifacts/src/web/ui4a/manifest.ts` is the source of truth for the generated `skills/ui4a/SKILL.md`.

| Module | Purpose |
| --- | --- |
| `$ui4a/ui` | Button, Field, Card, Badge, Tabs, and Disclosure |
| `$ui4a/ui/katex` | LaTeX and MathBlock with stable formula rendering |
| `$ui4a/ui/charts` | Responsive Recharts components with streaming snapshots and stable data/axes |
| `$ui4a/chat` | Send a visible user message after an explicit user action |
| `$ui4a/state` | Session- and surface-scoped JSON persistence |
| `$ui4a/fs` | Read and write files below `.artifacts` |

Native HTML and Wind4 utilities handle layout, and Headless UI can be imported for additional controls. Prefer the bundled chart and formula modules for mathematical explanations: combine a formula, a restrained line chart and numeric sliders driven by the same state. UI4A code runs as trusted local React in the host page; it is not an isolation sandbox for arbitrary third-party code.

## Authoring rules

The generated skill requires a default React export, stable component and import names during streaming, accessible labels, useful empty states, and explicit user actions before sending messages or writing files. It forbids invented `$ui4a/*` modules, credential storage, command execution, and directory listing.
